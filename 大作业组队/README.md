# 机器人定位与导航大作业 —— 组队名单

[← 返回课程主页](../README.md)

> 本页用于登记大作业的组队信息。**请勿直接修改 `roster.csv`**，按下面的方式提交，系统会自动登记。

---

## 一、一键报名

直接点下面这个链接，会跳到已选好模板的报名页：

**https://github.com/haolingguang/SLAM-Experiments/issues/new?template=team-signup.yml**

或者在仓库页面：**Issues** → **New issue** → 选 **「组队报名」**。

填完点 **Submit new issue** 提交即可。

提交后约 10 秒，机器人会在下方回复结果：

| 结果 | 说明 | 你还需要做什么 |
| :-- | :-- | :-- |
| ✅ **登记成功** | 已写入名单，并告诉你分到第几号 | 什么都不用做 |
| ❌ **登记未通过** | 用红字列出原因，比如重名、队名被占用 | 点右上角 **Edit** 改完保存，自动重新校验 |

需要填的内容：

- 队伍名称（全仓库唯一）
- 成员1（队长，必填）
- 成员2 / 成员3（没有就留空）
- 队长联系电话（可留空）

---

## 二、规则

- **每队只由队长提交一次**，队员不要重复提交。
- 每队 **1 ~ 3 人**。
- 一个人**只能加入一支队伍**，出现重名会被拦下。
- 队伍名称不能重复。
- 报名截止后老师会锁定 Issues，届时以本表为准。

### 中途想改成员？

直接 **Edit** 你提交的那个 Issue，保存后系统会自动覆盖原来那一行，序号不变。

### 想取消报名？

在该 Issue 右侧 **Labels** 里加上 `取消报名` 标签，系统会自动清空你这一行。

## 四、常见问题

**Q：提交后一直没反应？**
A：进 **Actions** 标签页看「组队报名自动登记」这次运行是否成功。显示黄点表示还在排队，刷新稍等。

**Q：打不开 GitHub / 注册不了账号？**
A：请联系老师，用班级群里的在线表格作为备用报名渠道，最终由老师统一录入本表。

**Q：为什么不直接在表格里填？**
A：直接改文件容易互相覆盖、改坏格式。用 Issue 提交，系统会替你查重和校验，谁改了哪一行都有记录，不会冲突。
